# 車廂角落 Carriage Corner

同在，但不必言語。一節永遠在行駛的北城捷運 TPRT 車廂。完整規格見 [docs/PRD.md](docs/PRD.md)。

## 目前進度：M0 技術驗證 ＋ M2 多人連線

**車廂場景（M0）**

- 像素完美渲染管線：640×360（直式隨螢幕寬度調整）RenderTexture → 整數倍放大
- 程序化占位美術：車廂內裝、4 種乘客 × 5 種狀態（2～4 幀）、三條虛構路線的車窗景觀
- 光影與粒子：晨間光柱、夜間霓虹窗形光斑、隧道掃光、出隧道閃光、雨絲、玻璃水珠、咖啡熱氣、Zzz
- 霧氣留言：寫字處擦開霧氣、筆劃邊緣聚水，再有機地重新凝結
- 音效：原生 Web Audio 混音器；鐵軌、雨聲、Lo-Fi 為程式合成的占位音（零授權風險），鐵軌聲依地下／高架切換低通濾鏡
- HUD：狀態切換、番茄鐘、音效面板、霧氣留言、單向微光、勿擾、連線狀態

**即時連線（M2，`apps/server`）**

- Socket.io 伺服器，伺服器權威：座位、列車時鐘、到站／發車、NPC 熱度維持
- 車廂分流：未滿 8 人先挑最熱鬧的、8 人後挑最空的、12 人全滿才加開；座位依「隔一個位子、避開博愛座」
- 斷線寬限：座位保留、他人眼中變成補眠；同一分頁重新整理以 resumeToken 回到原座位；離線超過 60 秒在下一站下車
- 微光：不帶送出者、勿擾時靜默丟棄但送出者仍看到成功；收到者只有自己看得到提示
- 霧氣留言：伺服器過濾（聯絡方式、詞庫、長度）、自傷字詞改走關懷流程（顯示 1925 安心專線，不廣播）、每站一則、3 人檢舉即移除並影子靜音作者
- 限流：每種事件都有 token bucket
- 連不上伺服器時自動改用**離線模式**（本機模擬 NPC 與列車），左上角紅點標示

**車票明信片（M3）**

- 🎫 車票：在瀏覽器內產生 1080×1350 PNG（像素圖層 216×270 放大 5 倍＋清晰文字），含路線、起訖站、座位、隨行卡卡面、乘車時間、專注／咖啡／點頭次數、同車人數、語錄（可「換一句」）、序號與 QR Code
- 可選擇附上自己寫在車窗上的話：只印在本機圖片上，不會進公開連結
- 分享：手機用系統分享（含圖片）；不支援時下載圖片；Threads／IG／LINE 內建瀏覽器改為長按存圖；另有「複製文案」與「到 Threads 發文」（官方 Web Intent，連結放在文字中）
- 分享連結 `/t/:token`：伺服器簽章、無資料庫、只含代碼與數字；落地頁有 OG 標籤與「搭上同一條線」按鈕（`/?line=XX` 預選路線）
- OG 預覽圖 `/og/t/:token.png`：1200×630 像素風，用內建點陣字直接編碼 PNG，不需字型檔

尚未包含：Redis（目前全在記憶體，單節點）、正式美術與 CC0 音源、限動版 1080×1920 車票。

## 開發

需要 Node.js 22 以上。專案使用 npm workspaces（PRD 原訂 pnpm，因開發機未安裝而改用 npm，結構相同）。

```bash
npm install
npm run dev
```

同時啟動前端（http://127.0.0.1:5188/）與即時伺服器（:5189，前端經 Vite proxy 同源連線）。只要前端時用 `npm run dev:web`，會自動進入離線模式。

用兩個分頁（或兩台裝置）選同一條線進站，就會坐進同一節車廂。

開發用網址參數：

| 參數 | 說明 |
|---|---|
| `?dev=1` | 顯示「切換晨／夜」按鈕；console 可用 `store`、`mixer`、`__pax()`、`__train()`、`__notes()` |
| `?mode=morning` ／ `?mode=night` | 固定時間模式（預設依裝置時間） |
| `?run=40&dwell=10` | 離線模式的行駛／停站秒數 |
| `?pomo=1` | 番茄鐘專注分鐘數 |
| `?noteTtl=60` | 離線模式的霧氣留言存活秒數 |

伺服器環境變數（皆可省略）：

| 變數 | 預設 | 說明 |
|---|---|---|
| `REALTIME_PORT` | 5189 | 即時伺服器埠號 |
| `RUN_MIN_SEC` ／ `RUN_MAX_SEC` | 45 ／ 70（正式 300 ／ 600） | 每段行駛秒數範圍 |
| `DWELL_SEC` | 14（正式 20） | 停站秒數 |
| `GRACE_SEC` | 60 | 斷線保留座位秒數 |
| `NOTE_TTL_SEC` | 480 | 霧氣留言存活秒數 |
| `TOKEN_SECRET` | 每次啟動隨機 | resumeToken 簽章金鑰，**正式環境必填** |
| `WEB_ORIGIN` | 本機 5188 | 允許連線的前端來源（逗號分隔） |
| `NOTES_PAUSED` | — | 設為 `1` 時全站暫停霧氣留言 |
| `PUBLIC_ORIGIN` | 依請求的 Host | 車票落地頁 og:image 用的對外網址，例如 `https://carriage.example` |

正式模式：`npm start -w @cc/server`（帶 `--production`，行駛時間改為 5～10 分鐘）。

```bash
npm run typecheck
npm test
npm run build
```

`npm test` 會啟動真正的伺服器，用 socket.io client 驗證分流、微光匿名、勿擾、留言過濾與檢舉、斷線重連、到站下車；並驗證車票簽章、竄改防護、落地頁 OG 標籤與 PNG 預覽圖格式。

## 結構

```
apps/web/          前端（Vite + TypeScript + PixiJS v8 + React + Tailwind）
  src/game/        車廂場景：渲染管線、占位美術、景觀、玻璃、光影、乘客、列車時鐘
  src/net/         連線：進站、時鐘校正、斷線重連
  src/audio/       AmbientMixer 與程式合成的占位環境音
  src/ui/          React HUD
apps/server/       即時伺服器（Node.js + Socket.io + Zod）
  src/rooms/       Room（座位、列車、NPC、留言）與 RoomManager（分流）
  test/            整合測試
packages/shared/   前後端共用：協定型別、虛構路網、就座規則、語錄、文字工具
docs/PRD.md        開發規格書
```
